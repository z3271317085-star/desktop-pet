# 使用示例

## 从真人照片开始

```text
初始化不一书桌宠生成器。我想把这张照片做成像素风 Codex 桌宠，保留眼镜、灰色上衣和绿色编织包。
```

## 从一张宠物照片开始

```text
使用 $bys-codex-pet 把我的猫做成 Codex 桌宠。照片只有一张，其他角度请合理推断，每个阶段先让我确认。
```

## 没有图片

```text
用不一书桌宠生成器做一只蓝色、戴小围巾、性格安静的云朵桌宠。
```

## 恢复项目

```text
继续我的不一书桌宠项目，从上次角色定稿确认的位置继续。
```

## 导出分享包

```text
把已经安装的桌宠导出成 Windows 和 macOS 都能安装的分享包，默认使用中文说明。
```
